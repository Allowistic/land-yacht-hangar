# Land Yacht Bay 04

WebXR hangar inside a dune land-yacht on a procedural alien planet.

Mauve observation bay, hull + six wheels + sail outside the glass, fBm dunes/ridges/mesas scrolling under the keel. Quest Browser + ENTER VR. Trigger starts a generated lofi bed.

## Run

```bash
npm install
npm run dev
```

Quest on the same LAN → `https://YOUR_IP:5173` → accept the cert → **ENTER VR**.

```bash
npm run build
npm run preview
```

## Stack

Three.js + WebXR (`local-floor`, VRButton, controllers). Vite + basic-ssl for HTTPS.

Repo: https://github.com/Allowistic/land-yacht-hangar
